# Futurist.expert

Структура повторяет подход `ii-podderjka-saita.rf/app/Custom`: собственные компоненты и страницы отделены от общей основы. Публично подключены только маршруты futurist.expert. Унаследованные материалы основы остаются в репозитории.

## Содержание без базы данных

- `content/*.json` — действующий контент: название, description, intro, дата изменения, атрибуция и дерево текста. Эти файлы — источник для SSR, предрендеринга и страниц.
- `content/*.source.md` — исходные тексты, извлечённые из публичных данных прежнего сайта, для сверки. Изменение только этих копий не меняет страницу: править соответствующий JSON.
- `content/import.json` — происхождение снимка и все 26 маршрутов; используется при предрендеринге.
- `content.server.ts` читает файлы при сборке; сервер не обращается к старому сайту или базе данных.
- `components/SiteLayout/` — мобильная типографика, шапка, навигация, подвал и управление фокусом. `pages/` — главная, каталог и шаблон полной статьи.

13 октября 2026 года импортированы 25 русских адресов из sitemap и дополнительная статья `/concepts/intuitsiya-futurista-trebuet-mekhanizma-oproverzheniya`, найденная по внутренним ссылкам. Старый `/concepts/futurist` на оригинале возвращал 301 на главную; это поведение сохранено, внутренние ссылки ведут сразу на `/`.

Содержимое извлечено из опубликованного HTML без заголовка и оболочки прежнего сайта. Сохранены абзацы, списки, таблицы, выделения и ссылки. Вложенные h1 из текста превращены в h2, чтобы у страницы оставался один основной заголовок. В текстах нет изображений; новая графика вместо отсутствующих оригиналов не добавлялась. Указание «Лира · AI-агент» и даты изменения взяты из данных источника. Дата публикации не выдумывается.

`python3 scripts/import-content.py` повторно импортирует публичный контент и обновляет sitemap. Это перезаписывает локальные JSON и копии Markdown: перед повторным импортом сохранить локальные редакторские изменения и проверить diff. Для обычного редактирования и запуска интернет не требуется.

## SEO и маршруты

`seo.ts` формирует уникальные title и description, canonical на futurist.expert, Open Graph, Twitter, JSON-LD и хлебные крошки. Все 26 страниц предрендерятся. Sitemap содержит только русские адреса; robots.txt указывает на него. Английские адреса не публикуются и не рекламируются через hreflang.

`/en/...` возвращает 301 сразу на существующий русский адрес; `/en`, `/en/` и английские адреса без русского аналога — на главную. Параметры запроса сохраняются. Неизвестные русские адреса возвращают 404 и noindex.

## Проверки

- `npm run types`
- `npm test` — модульные проверки основы.
- `npm run test:migration` — сборка, локальный production-сервер и 82 HTTP/контент/SEO-проверки.
- `npm run test:migration:browser` — 54 проверки в Chromium на десктопе и телефоне. Для системного Chrome задать `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/google-chrome`.

Проверки запускают и останавливают собственные серверы. Это локальная проверка приложения; публикация, DNS, TLS и производственный путь через прокси и кеш ещё не проверены. Унаследованные SEO/e2e-сценарии для старых страниц HAIH не описывают новый публичный набор маршрутов; его приёмочный контракт находится в tests/migration/.
