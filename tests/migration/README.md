# Контракт переноса futurist.expert

Содержание будущего сайта хранится в файлах репозитория, без базы данных.
Снимок sitemap задаёт адреса и ожидаемое поведение, но не заменяет файлы с текстами страниц.

- `npm run sitemap:snapshot` скачивает индекс и вложенные sitemap, сохраняет исходный XML, контрольные суммы и `manifest.json`. Английские адреса сопоставляются с русскими по `hreflang="ru"` исходного sitemap. Перед принятием нового снимка проверить diff: удалённые адреса не должны незаметно исчезнуть из контракта переноса.
- `npm run test:migration` собирает приложение, запускает настоящий production-сервер на свободном локальном порту, проверяет каждый адрес и завершает сервер. Запросы направляются только на локальный сервер, внешние сборщики статистики отключены. Интернет и база данных для самих тестов не нужны.
- `npm run test:migration:built` повторяет проверки уже собранной версии.

Для русских страниц ожидаются HTTP 200, HTML с `lang="ru"`, title, h1 и canonical конкретной страницы на futurist.expert. Для `/en/...` — HTTP 301 на соответствующую русскую страницу, затем её успешный ответ без второй переадресации. Дополнительно проверяются `/en` и неизвестный адрес с 404. Проверка XML и контрольных сумм защищает от потери адресов в manifest.

Это приёмочные тесты переноса. После переноса 26 страниц они проходят; дополнительно проверяются SEO, полный текст из файлов, внутренние ссылки и новый sitemap. Не подменять страницы заглушками и не ослаблять тесты ради зелёного результата. Наличие правильного HTTP-ответа и метаданных ещё не доказывает полноту переноса текстов, изображений и интерактивных функций; их проверяют при переносе отдельно.

Браузерные проверки: `npm run test:migration:browser`. Нужен Chromium Playwright либо переменная `PLAYWRIGHT_CHROMIUM_EXECUTABLE` с путём к установленному Chrome. Проверяются все 26 страниц на ширине 390 и 1440 px, полный текст, ошибки гидратации, переполнение, SPA-навигация, история, фокус и canonical.
